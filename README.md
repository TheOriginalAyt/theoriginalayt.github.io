# Antigravity Personal Portfolio Website Template

A premium, highly interactive personal portfolio website template designed for static hosting on **GitHub Pages**. It features a modern, responsive single-page application (SPA) dashboard styled with a sleek **Marina Blue** and **Dark Gray** color palette.

To wow technical recruiters and protect content from low-effort automated scrappers, the landing page features an immersive, gamified **"Bot-Proofing" lockscreen gate**!

---

## 🌟 Features

1. **Security Lockscreen Gate**:
   - **Terminal CLI Bypass**: Retro-hacker CLI supporting diagnostic command inputs like `help`, `about`, `skills`, `projects`, `matrix`, `clear`, and `unlock`.
   - **Visual Grid Bypass**: Connect glowing nodes in a sequence from Left to Right to establish a security handshake.
   - Smooth matrix-fade transition upon successful unlocking.
   - Session storage state tracking to avoid re-locking during active browsing.
2. **Dashboard Portfolio**:
   - **Floating Navigation Bar**: Glassmorphic styling with smooth `:hover` indicators.
   - **Interactive Resume**: A clean sidebar with social/email contacts, a PDF download button, a vertical visual timeline for experience, education grids, and an accordion of technical skill badges.
   - **Project Showcase**: A customizable grid of responsive cards with glow-on-hover effects and categories filtering buttons.
   - **Blog posts reader**: Integrates an elegant markdown parser to display full-length blog articles directly inside the viewport via an overlay modal.
   - **Hobbies Grid**: Visual interest panels featuring custom micro-animations.
3. **Responsive Themes**: A high-end native dark/light mode toggle that stores user preferences in `localStorage`.
4. **Decoupled Content Architecture**: All textual data resides in a modular database file (`public/resume.json`). **You do not need to edit complex HTML blocks to update your resume!**

## 🛠️ Quick Start (Local Development)

This template uses **Vite** for fast, local development hot-reloading:

1. **Install dependencies**:
   ```bash
   npm install
   ```
2. **Start the local dev server**:
   ```bash
   npm run dev
   ```
3. **Open in browser**:
   Click on the local server link generated by Vite (usually `http://localhost:5173`).

## 🚀 Deploying to GitHub Pages

Since the template contains only static assets (HTML, CSS, JS), hosting on GitHub Pages is free and takes just a minute:

### Method A: Direct Upload
1. Build the production files:
   ```bash
   npm run build
   ```
   *This outputs optimized static files inside a `dist/` directory.*
2. Drag and drop the contents of the `dist/` directory into your GitHub Repository.
3. In your Repository settings, navigate to **Pages** and set the source branch to `main` (or `gh-pages`) and path to `/ (root)`. Save!

### Method B: Native Deploy (No Build Steps)
If you don't want to run build steps, you can directly push the raw root folder (excluding `node_modules` via `.gitignore`):
1. Push `index.html`, `css/`, and `js/` to your repository.
2. Under Repository **Settings** ➡️ **Pages**, set deployment source to **Deploy from a branch**.
3. Choose the `main` branch, folder `/ (root)`, and click **Save**!
